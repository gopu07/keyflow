# Security Policy

## Supported Versions

We actively support and fix security issues in the following versions of Keyflow:

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do **not** open a public issue. Instead, report it privately to ensure the security of users and hosts.

Please send an email to **devraj.solanki.dev@gmail.com** with details of:
- The nature of the vulnerability (e.g. CSRF, XSS, database leakage, dependency risk).
- Steps to reproduce or a proof of concept (PoC).
- Potential impact on users or rooms.

We will acknowledge your report within 48 hours and coordinate a disclosure timeline once a fix is prepared.
